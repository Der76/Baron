# Assessment 3.2: Linear Data Structure

Author: Baron

Dynamic Python programs made in PyCharm. Each program is in its own file.
The user types a word, and the program shows each step until the structure is empty.

| File | Linear Data Structure |
|------|-----------------------|
| 1_array_program.py | Array (list) |
| 2_singly_linked_list_program.py | Singly Linked List |
| 3_stack_program.py | Stack (LIFO) |
| 4_queue_program.py | Queue (FIFO) |

## How to run
Open a file in PyCharm, right-click inside the code, choose Run, then type a word (example: SAMSON).
